# Sicurezza e segnalazioni

## Cosa segnalare
- Istruzioni nelle skill che potrebbero indurre a test non autorizzati, a esporre dati o a dichiarare risultati non dimostrati.
- Script che gestiscono in modo insicuro file, percorsi o dati sensibili.
- Link o riferimenti errati o rimossi, richieste di correzione da parte dei titolari delle fonti.

## Come segnalare
Per questioni riservate usa la funzione **«Report a vulnerability»** (Security advisories) del repository su GitHub, senza aprire una issue pubblica. Per correzioni non sensibili va bene una issue o una pull request (vedi `CONTRIBUTING.md`).

## Uso responsabile
Le skill sono pensate per assessment **autorizzati**. Non usarle per accedere a sistemi di cui non hai titolo né per aggirare le regole di ingaggio che prevedono. Gli autori non rispondono dell'uso improprio (vedi `LICENSE` e `NOTICE`).

## Versioni supportate
Viene mantenuta l'ultima versione pubblicata.
