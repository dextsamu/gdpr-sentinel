# Contribuire

Grazie dell'interesse. Contributi benvenuti: correzioni di link e fonti, miglioramenti ai checklist, nuovi template, bug negli script.

## Prima di aprire una pull request
1. **Un cambiamento per PR**, con una frase che spiega *perché*.
2. Le skill seguono una regola di fondo: **niente affermazioni non dimostrate**. Non aggiungere istruzioni che permettano di dichiarare test eseguiti senza prova o conformità legale.
3. Mantieni `SKILL.md` snello (sotto le 500 righe): il dettaglio va in `references/`.
4. Gli script usano solo la libreria standard di Python (`jsonschema` è opzionale). Esegui gli script sui template prima di inviare.
5. Se cambi un link o uno standard, aggiorna la data di revisione nel file delle fonti.
6. Non inserire nomi di clienti, applicativi privati, dati personali o segreti, nemmeno come esempio.

## Sicurezza
Se trovi un problema nelle istruzioni che potrebbe indurre a test non autorizzati o a esporre dati, segnalalo in privato al maintainer prima di aprire una issue pubblica.

## Licenza dei contributi
Inviando un contributo accetti che sia rilasciato con licenza Apache-2.0, come il resto del progetto.
